Security follows OWASP ASVS verification requirements:

- All authentication, session, and access-control code MUST be reviewed against ASVS Level 1 controls minimum.
- Code touching cryptography or sensitive data SHOULD additionally satisfy ASVS Level 2.
- Security-relevant changes MUST be tested with both positive and abuse cases.

> Source: OWASP Application Security Verification Standard — https://owasp.org/www-project-application-security-verification-standard/.

What L1 actually ships today.

Nine features, four workflow skills, one pre-commit hook — and a one-command exit.

What you get week one // 9 features

Standards. A CLAUDE.md generator inside the 150-instruction budget, a git-based rules engine with glob matching, an architecture-pattern library, and OWASP-aligned security templates.

Workflow. Four Agent Skills for issue creation, implementation, review, and test generation.

Quality. A pre-commit hook engine running lint, types, tests, and secret-scan.

The 4 workflow skills // /3c-*

  • /3c-create-issue — structured GitHub issues; no auto-attached state.
  • /3c-implement — fetch → plan → branch → TDD → review → PR, with a destructive-op interlock. Never auto-merges or force-pushes.
  • /3c-review — read-only checklist over the branch diff; findings with file/line/severity.
  • /3c-test — tests in your framework + conventions; never overwrites existing tests unprompted.

The pre-commit hook // 10s budget

One synchronous orchestrator runs every configured gate before a commit lands — lint, typecheck, unit tests, secret scan — inside a 10-second budget on a 500-file repo.

A failed gate blocks the commit with a remediation message. An emergency bypass exists and is audited — it's a recorded decision, not a back door.

Leaving is one command // reversible

git revert the PR that added .claude/ (or git rm -r .claude/). What remains afterwards: nothing of 3C's.

No daemon, no global package, no workstation state, no backend. The .claude/ tree is the entire footprint — plain version-controlled files you can read before you trust them.
